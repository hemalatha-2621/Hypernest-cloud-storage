# Supabase Dashboard Setup

To make your app work on **GitHub Pages**, you must run the SQL commands found in the new file:

### 👉 [setup_storage.sql](setup_storage.sql)

1. Open **[setup_storage.sql](setup_storage.sql)**.
2. **Copy EVERYTHING** inside that file.
3. Go to your **Supabase Dashboard** -> **SQL Editor**.
4. **Paste and Run** the code.

> [!IMPORTANT]
> Do NOT copy this Markdown file into the SQL editor. Only copy the content from the `.sql` file.
